# EODigitalTwins

Welcome to **EODigitalTwins**, a living Jupyter Book for Earth Observation Digital Twins.

This repository provides a structured place for concepts, architectures, use cases, executable examples, and implementation guidance. Replace the starter text with your project material as the book develops.

## Purpose

The book is designed to support collaborative, version-controlled publication through GitHub and automatic deployment through GitHub Pages.

## Contents

- Earth Observation Digital Twin concepts
- Reference architecture
- Use cases
- Executable notebook examples
- Implementation roadmap
- Glossary and references
